# CEPROC

Sitio web institucional de la Asociación CEPROC, organización sin fines de lucro dedicada al desarrollo sostenible y la acción comunitaria en Bolivia.

## Acerca del proyecto

Este proyecto es la migración del sitio institucional de CEPROC, originalmente desarrollado en PHP, a Astro.

La página presenta información sobre la organización, su misión y visión, las áreas de trabajo, el alcance de sus proyectos en Bolivia y el portafolio de proyectos.

## Tecnologías

- Astro
- TypeScript
- Bootstrap 5
- AOS
- anime.js
- Font Awesome
- Fontsource
- npm

## Requisitos

- Node.js 22 o superior
- npm 10 o superior

## Instalación

```bash
git clone https://github.com/OogieBogiee/ceproc_landing.git
cd ceproc_landing
npm install
```

## Desarrollo

```bash
npm run dev
```

El servidor de desarrollo se inicia en `http://localhost:4321`.

## Producción

```bash
npm run build
npm run preview
```

Los archivos generados se guardan en `dist/`.

## Rutas

- `/` redirige a `/es/`.
- `/es/` versión en español.
